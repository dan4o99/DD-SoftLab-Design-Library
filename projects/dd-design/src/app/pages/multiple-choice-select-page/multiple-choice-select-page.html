Multiple Choice Select

Select multiple options with inline chips.

Default (`searchable = false`)

Searchable (`searchable = true`)

Disabled (`disabled`)

Inputs

  • options: Array<{{ '{' }} id, label {{ '}' }}>, value: string[]
  • label, ariaLabel, disabled, searchable, searchPlaceholder
  • customClass, customStyle

Outputs

  • changed: string[]
  • clicked: string
