Toast

Transient notifications injected via DdToastService.

Place <dd-toast-container /> once in your app root (e.g., app.html).

Info toast Success toast Warning toast Error toast

DdToastService

  • show(message, options?): string — returns toast id
  • dismiss(id): void
  • clear(): void

DdToastContainerComponent inputs

  • position: 'top-right' | 'top-left' | 'bottom-right' | 'bottom-left'

Toast options

  • variant: 'info' | 'success' | 'warning' | 'danger'
  • title: string
  • duration: number (ms, 0 = persistent)
