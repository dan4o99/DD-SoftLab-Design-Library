Skip Link

A visually hidden anchor that becomes visible on focus, allowing keyboard users to skip navigation.

Usage

The skip link is visually hidden until focused. Tab into the area below to see it appear:

The link below is rendered but hidden — press Tab to see it reveal at the top of the viewport.

#main-content — the skip target

Inputs

  • target: string — id of the target element (default: main-content)
  • label: string — link text (default: "Skip to main content")
